# Dudex AI 🚀
### LLM-Powered Startup Execution Platform

An intelligent full-stack AI platform that converts raw startup ideas into structured execution plans, complete with milestones and task breakdowns.

---

## 🌟 Overview

Dudex AI is a production-grade platform designed to bridge the gap between early-stage ideation and execution. By leveraging the Gemini API, the system processes startup concepts and breaks them down into actionable milestones, roadmaps, and tasks with ultra-low latency and strict structured outputs.

---

## 🛠️ Tech Stack

* **Frontend:** TypeScript, React, CSS / HTML
* **Backend:** Node.js, Python, Flask, REST APIs
* **AI & LLM:** Google Gemini API, Prompt Engineering, Structured Output Parsing
* **Database & Deployment:** Supabase, Vercel, Docker & Docker Compose

---

## ✨ Key Features

* **🧠 Automated Execution Breakdown:** Instantly transforms an idea description into a structured, milestone-driven roadmap.
* **⚡ High-Performance Processing:** Built with concurrent session handling, input sanitization, and response caching to keep response times consistently under two seconds.
* **🎯 High-Compliance Structured Outputs:** Iteratively optimized across 200+ test cases to resolve LLM variance, reaching 92% parsing compliance.
* **🐳 Containerized Architecture:** Easily spin up the entire stack locally using Docker.

---

## 📦 Project Structure

* **backend/** - Python AI services and API server
* **frontend/** - Web dashboard and UI interface
* **docker-compose.yml** - Container orchestration configuration
* **start.bat** - Windows quick-start script
* **start_docker.bat** - Docker execution script

## ⚙️ Getting Started

### Prerequisites
Ensure you have the following installed on your machine:
* Node.js (v18+)
* Python (v3.10+)
* Docker Desktop (for containerized execution)

### Local Installation
1. Clone the Repository:
   `git clone https://github.com/Dudexai/Dudex-AI.git` and enter the directory.
2. Setup Frontend:
   Navigate to the frontend folder, install dependencies, and run the development server.
3. Setup Backend:
   Navigate to the backend folder, install requirements, and run the server.

### 🐳 Running with Docker
To spin up the entire application stack using Docker, use Docker Compose or run the provided batch script on Windows.
